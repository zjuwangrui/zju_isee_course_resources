# `audio_animator.py` 动画生成关键参数说明

本文档说明 [`py_tools/audio_animator.py`](./audio_animator.py) 当前生成时频动画时用到的关键参数、常见取值，以及这些参数对最终动画观感的影响。

## 1. 核心参数总览

| 参数 | 当前位置 | 当前默认值 | 常见值 | 主要影响 |
| --- | --- | --- | --- | --- |
| `sr` | `create_spectrogram_animation()` | `44100` | `22050`、`32000`、`44100`、`48000` | 频率上限、细节保留程度、计算量 |
| `n_fft` | `create_spectrogram_animation()` | `2048` | `512`、`1024`、`2048`、`4096` | 频率分辨率、时间分辨率、谱图平滑程度 |
| `hop_length` | `create_spectrogram_animation()` | `512` | `128`、`256`、`512`、`1024` | 帧间时间步长、动画平滑度、视频帧率 |
| `window_size` | `update()` 内部固定值 | `10` | `6`、`8`、`10`、`12`、`16` | 屏幕中同时显示的时间宽度 |
| `cmap` | `imshow()` | `"viridis"` | `"viridis"`、`"magma"`、`"inferno"`、`"plasma"` | 颜色风格、强弱对比的主观感受 |
| `figsize` | `plt.subplots()` | `(10, 6)` | `(8, 4.5)`、`(10, 6)`、`(12, 7)` | 画面纵横比、清晰度、构图 |
| 音频混流参数 | `_add_audio_track()` | `AAC 192k` | `128k`、`192k`、`256k` | 背景音乐音质、最终文件大小 |
| 窗函数 | `stft_analyzer.stft()` | 矩形窗 | 矩形窗、Hann 窗、Hamming 窗 | 频谱泄漏、条纹锐利程度 |

## 2. 各参数的作用与常见效果

### `sr`

- 含义：读入音频时使用的采样率。
- 当前代码：`librosa.load(input_path, sr=sr)`。
- 直接影响：
  - 频率轴最高只能显示到 `sr / 2`。
  - `sr` 越高，高频细节保留越多，但数据量也越大。
  - 在 `hop_length` 不变时，`fps = sr / hop_length` 也会变大。
- 常见取值建议：
  - `22050`：计算更轻，适合只看总体轮廓。
  - `44100`：音乐分析最常见，兼顾细节和兼容性。
  - `48000`：视频领域常见，适合和影视音频统一。
- 动画观感：
  - 较高 `sr` 会让高频区域更完整。
  - 若原音频本身高频内容不多，盲目提高 `sr` 对视觉提升有限。

### `n_fft`

- 含义：每一帧做 FFT 时使用的窗长，也决定频率采样点数。
- 当前代码：手写 STFT 调用 `manual_stft(..., n_fft, frame_shift=hop_length)`。
- 直接影响：
  - `n_fft` 越大，频率分辨率越高，横向谐波条纹更细、更清楚。
  - `n_fft` 越大，时间定位越模糊，瞬态边界会更“拖尾”。
  - `n_fft` 越小，节奏变化更敏捷，但频率纹理更粗。
- 常见取值建议：
  - `512`：适合节奏型、鼓点、快速瞬态。
  - `1024`：比较均衡。
  - `2048`：音乐时频图很常见，兼顾谐波与时间变化。
  - `4096`：更适合看稳定音高和细密谐波，但动画会显得更“慢”。
- 动画观感：
  - 大 `n_fft`：音高线条清楚，竖向过渡变慢。
  - 小 `n_fft`：切换敏捷，但频率层次会变厚、变糙。

### `hop_length`

- 含义：相邻两帧 STFT 的步长。
- 当前代码中有两个作用：
  - 传给手写 STFT 作为 `frame_shift`。
  - 决定动画帧率 `fps = sr / hop_length`。
- 直接影响：
  - `hop_length` 越小，时间采样越密，动画更顺滑。
  - `hop_length` 越大，帧数越少，动画更省时，但会更跳。
  - 对应的时间步长是 `hop_length / sr` 秒。
- 常见取值建议：
  - `128`：很平滑，但渲染慢。
  - `256`：平滑度较好。
  - `512`：常见折中值。
  - `1024`：更适合快速预览。
- 动画观感：
  - 小 `hop_length`：画面滑动连续，音画同步感更强。
  - 大 `hop_length`：画面像按时间片跳动，细节容易丢。

### `window_size`

- 含义：动画窗口一次显示多少帧时频数据。
- 当前代码：`update()` 里固定为 `10`。
- 直接影响：
  - 实际可见时间跨度约为 `window_size * hop_length / sr` 秒。
  - 这不是 STFT 的窗长，而是动画视窗宽度。
- 常见取值建议：
  - `6` 到 `8`：镜头更紧，运动感更强。
  - `10`：较均衡。
  - `12` 到 `16`：画面更宽，便于观察上下文。
- 动画观感：
  - 小 `window_size`：像“跟拍”，更聚焦当前瞬间。
  - 大 `window_size`：能同时看到更长时间片段，但滑动感减弱。

### `cmap`

- 含义：时频强度映射到颜色的方式。
- 当前默认值：`"viridis"`。
- 常见取值建议：
  - `"viridis"`：均衡、通用、层次清楚。
  - `"magma"`：暗背景下对比更强。
  - `"inferno"`：亮部强调明显，冲击力更强。
  - `"plasma"`：颜色更鲜艳。
- 动画观感：
  - 颜色并不改变真实数据，但会显著改变“强弱是否明显”的主观感受。
  - 报告和演示中，`viridis` 最稳妥；展示感更强时可试 `magma` 或 `inferno`。

### `figsize`

- 含义：画布尺寸，当前为 `figsize=(10, 6)`。
- 常见取值建议：
  - `(8, 4.5)`：更接近 16:9。
  - `(10, 6)`：当前默认，兼顾宽度与高度。
  - `(12, 7)`：适合高清输出。
- 动画观感：
  - 更宽的画幅更适合视频展示。
  - 更高的画幅会让低频和高频区分得更开。

### 音频混流参数

- 含义：把原始音频用 `ffmpeg` 混入最终 MP4。
- 当前代码：`-c:a aac -b:a 192k -shortest`。
- 常见取值建议：
  - `128k`：文件更小。
  - `192k`：兼顾音质与体积。
  - `256k`：音质更稳，但文件更大。
- 动画观感：
  - 不改变图像本身，但显著提升“这是完整视频作品”的感受。
  - `-shortest` 会让视频和音频以较短者为准结束，避免尾部黑屏或静音拖尾。

## 3. 当前实现中的固定策略

### 只显示正频率部分

- 当前代码只保留 `0 ~ sr/2` 的频率范围。
- 这是音频谱图的常见做法，因为实信号的负频率部分通常不单独展示。
- 视觉上会让图像更紧凑，也更符合常见时频图阅读习惯。

### 关闭坐标轴

- 当前代码用了：
  - `fig.subplots_adjust(left=0, right=1, bottom=0, top=1)`
  - `ax.set_axis_off()`
- 效果是只保留主图，不显示坐标轴、边框和标题。
- 更适合把动画嵌入 PPT、报告视频或作为背景素材。

### 使用矩形窗

- 当前手写 STFT 里窗函数是 `np.ones(window_size)`，也就是矩形窗。
- 它的优点是实现简单、主瓣较窄。
- 它的缺点是频谱泄漏相对明显，某些频率附近可能会看到更粗的扩散条纹。
- 常见替代：
  - Hann 窗：更平滑，泄漏更小，音乐分析里很常见。
  - Hamming 窗：和 Hann 类似，也常用于一般谱分析。

## 4. 常用调参组合

### 组合 A：均衡型音乐展示

- `sr = 44100`
- `n_fft = 2048`
- `hop_length = 512`
- `window_size = 10`

效果：
适合大多数歌曲。谐波看得清，画面也不会过于跳动，是当前脚本最接近的默认风格。

### 组合 B：更平滑的动画

- `sr = 44100`
- `n_fft = 2048`
- `hop_length = 256`
- `window_size = 12`

效果：
画面滑动更连续，适合旋律线条较明显、希望“跟着音乐流动”的场景，但渲染时间会更长。

### 组合 C：突出瞬态变化

- `sr = 44100`
- `n_fft = 512`
- `hop_length = 128`
- `window_size = 8`

效果：
鼓点、敲击、短时变化更清楚，画面更灵敏，但频率纹理会更粗。

### 组合 D：突出音高和谐波

- `sr = 44100`
- `n_fft = 4096`
- `hop_length = 512`
- `window_size = 10`

效果：
稳定音高和谐波层更清楚，适合人声、弦乐、长音，但瞬态边界会更模糊。

## 5. 调参时最值得记住的结论

- 想让动画更顺滑，优先减小 `hop_length`。
- 想让频率线条更细、更清楚，优先增大 `n_fft`。
- 想让瞬态更敏捷、节奏感更强，减小 `n_fft` 和 `hop_length`。
- 想让画面一次看到更长的时间范围，增大 `window_size`。
- 想让最终视频更完整、更像成品，保留音频混流。
